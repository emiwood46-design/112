# Очистка Xiaomi TV от рекламы (аналог CleanMyTV)

Работает через ADB по Wi‑Fi. Root не нужен, приложения удаляются только для текущего пользователя, поэтому всё можно вернуть через `restore`. Сброс ТВ к заводским настройкам тоже всё вернёт.

## 1. Включите отладку на ТВ
1. Настройки → Настройки устройства → Об устройстве → 7 раз нажмите «Сборка» (включится режим разработчика).
2. Настройки → Настройки устройства → Для разработчиков → включите **Отладка по USB** (и «Отладка по сети», если такой пункт есть).
3. Узнайте IP-адрес ТВ: Настройки → Сеть и Интернет → ваша Wi‑Fi сеть.

Компьютер должен быть в той же сети, что и ТВ.

## 2. Запуск
**Windows:** скачайте [platform-tools](https://developer.android.com/tools/releases/platform-tools), распакуйте папку `platform-tools` рядом со скриптами и запустите `clean.bat`.

**macOS / Linux:** установите adb (`brew install android-platform-tools` или `sudo apt install adb`), затем `./clean.sh`.

Когда на ТВ появится окно «Разрешить отладку?», нажмите «Разрешить».

## Что делает скрипт
- сохраняет полный список пакетов в `backup-packages-*.txt`;
- находит на ТВ пакеты из `packages.txt` (реклама и телеметрия Xiaomi, промо-рекомендации Google, предустановленные приложения) и спрашивает про каждый;
- если пакет нельзя удалить, отключает его;
- чистит кэш приложений и по желанию ускоряет анимации.

Лаунчер PatchWall (`com.mitv.tvhome`) скрипт не трогает: без него ТВ останется без главного экрана. Свои пакеты можно добавить в `packages.txt`.

## Откат
`restore.bat` (Windows) или `./restore.sh` возвращает всё из `removed.txt`.
